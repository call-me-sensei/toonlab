## The five that matter most

If only a handful get fixed, these are the ones that cost this run the most:

1. **No preset-omission warning.** Three subsystems silently ran on an anonymous
   `default` preset or an overridden key, and each was then investigated as a
   missing capability. One line of `console.warn` on a bare factory call would
   have prevented the single largest defect of the run. — `GUIDE-12`
2. **Point agents at the labs.** 29 runnable labs carry the authored Call Me
   Sensei values; the skills say only "labs are authoring examples, not runtime
   dependencies", which reads as "not for you". — `GUIDE-01`
3. **`scene.fog` is hard-disabled on every environment material**, so the
   documented three-layer atmosphere cannot compose. — `env-scene-fog-disabled`
4. **No geometry-cast shadows** were obtainable at any setting. — `TL-047-NO-CAST-SHADOWS`
5. **`applyRockShader` silently falls back to a 64×64 noise swatch**, and the
   `{ textures }` escape hatch is in no skill, guide or MCP response. — `GUIDE-03`
