# 0.4.8 disposition of the 0.4.7 remediation checklist

This is the current release audit. The generated 0.4.7 checklist remains unchanged as historical evidence; unchecked boxes there do not mean the current code is still broken.

`resolved-0.4.8` means the code contract and an automated regression now exist. It is not a substitute for the final controlled P18 visual pass; rock/ground palette, shadows, cloud silhouette, shoreline, and underwater composition must still be captured before publication.

The audit parsed all **237** historical entries: **40 blocker**, **109 major**, **76 minor**, and **12 unclassified**. Every historical blocker has an explicit disposition; there are **zero unclassified 0.4.8 release blockers**.

## Release decision

- **Include in 0.4.8:** fixes to existing stable APIs and unsafe defaults: rock/ground lighting and shadows, rock detail/maps/wet band, grass package/LOD/provenance, cloud HDR/fog, water FogExp2/shore fallback/underwater atmosphere, shared model transcoders, texgen stripe variation, catalog metadata/R2 delivery, and skills/documentation.
- **Do not claim in 0.4.8:** a full Lighting System, automatic cliff builder, terrain burial solver, waterfall/cascade system, or heightfield-to-module planner. Those are new systems with separate design and visual acceptance work.
- **Keep as backlog:** remaining major/minor quality findings are preserved below. They are not silently closed and must be reconsidered for 0.4.10+ or when their owning public API changes.
